# API Reference

This reference documents the current Rich Wind HTTP API as implemented in `services/index.js`.

Base URL examples use `http://localhost:3001`.

## Common behavior

- All JSON endpoints accept `Content-Type: application/json`.
- IDs must match `^[a-zA-Z0-9._-]+$` and be <= `maxIdLength`.
- Security headers are added to responses:
  - `X-Content-Type-Options: nosniff`
  - `Referrer-Policy: no-referrer`
  - `X-Frame-Options: DENY`
  - `Cross-Origin-Resource-Policy: same-origin`
- Global rate limiting applies unless disabled.

## `POST /api/compile`

Compile CSS for a page and cache it by `projectId + pageId`.

### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `projectId` | string | yes | Alias: `project_id` |
| `pageId` | string | no | Alias: `page_id`, default: `"default"` |
| `html` | string | no | HTML to scan for classes |
| `classes` | string \| string[] | no | Explicit class list |
| `bundle` | string | no | default: `"full"` |
| `mode` | string | no | Alias for `bundle` |

At least one of `html` or `classes` is required unless bundle resolves to `base`.

### Bundle values

Normalized bundle modes:

- `base`: accepts `base`, `preflight`
- `theme`: accepts `theme`, `tokens`, `design`
- `utilities`: accepts `utilities`, `utility`, `utils`, `util`, `utilities-only`, `utility-only`
- `full`: default fallback for unknown values

### Response (200)

```json
{
  "success": true,
  "projectId": "demo",
  "pageId": "hero",
  "bundle": "full",
  "hash": "sha256...",
  "classes": ["bg-red-500", "text-white"],
  "cached": false,
  "css": "..."
}
```

### Errors

- `400`:
  - missing `projectId`
  - invalid `projectId`/`pageId`
  - missing both `html` and `classes` (except `base`)
  - no valid classes found
- `413`:
  - HTML too large
  - class string too large
  - class count exceeds `maxClassCount`
  - JSON payload too large (`entity.too.large`)
- `429`: rate limit exceeded (`Retry-After` header set)
- `500`: unexpected internal error

### Example

```bash
curl -X POST http://localhost:3001/api/compile \
  -H "Content-Type: application/json" \
  -d '{
    "projectId": "demo",
    "pageId": "hero",
    "html": "<div class=\"text-red-500\">Hello</div>",
    "classes": "bg-blue-500 p-4",
    "bundle": "full"
  }'
```

## `GET /api/css`

Return cached CSS for a specific page.

### Query params

| Param | Required | Notes |
| --- | --- | --- |
| `projectId` | yes | Alias: `project_id` |
| `pageId` | no | Alias: `page_id`, default: `default` |
| `bundle` | no | same normalization as compile |
| `mode` | no | alias for `bundle` |

### Response

- `200`: `text/css`
- `404`: cache miss (`POST /api/compile` first)

### Errors

- `400`: missing/invalid IDs
- `429`: rate limited
- `500`: internal error

### Example

```bash
curl "http://localhost:3001/api/css?projectId=demo&pageId=hero&bundle=utilities"
```

## `GET /api/projects/:projectId/css`

Return aggregated CSS for a project (union of class usage across cached pages).

### Params/query

| Field | Required | Notes |
| --- | --- | --- |
| `:projectId` | yes | validated like other IDs |
| `bundle` | no | same normalization as compile |
| `mode` | no | alias for `bundle` |

### Response

- `200`: `text/css`
- `404`: unknown project for non-`base` bundles
- `200` with `base` bundle even if project is missing

### Errors

- `400`: invalid `projectId`
- `429`: rate limited
- `500`: internal error

### Example

```bash
curl "http://localhost:3001/api/projects/demo/css?bundle=theme"
```

## `POST /api/suggest`

Return class suggestions from:

1. provided input classes
2. project cached class frequency
3. Tailwind static class list fallback (when enabled and `prefix` is provided)

Arbitrary value classes are not generated by fallback enumeration.

### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `projectId` | string | no | Alias: `project_id` |
| `prefix` | string | no | trimmed |
| `classes` | string \| string[] | no | included first in results |
| `limit` | number | no | aliases: `max`, `count` |

`limit` is clamped to configured `suggestLimit`.

### Response (200)

```json
{
  "success": true,
  "projectId": "demo",
  "prefix": "bg-",
  "count": 10,
  "suggestions": ["bg-blue-500", "bg-red-500"]
}
```

### Errors

- `400`: invalid `projectId`
- `429`: rate limited
- `500`: internal error

### Example

```bash
curl -X POST http://localhost:3001/api/suggest \
  -H "Content-Type: application/json" \
  -d '{ "projectId": "demo", "prefix": "bg-", "limit": 20 }'
```

## `GET /health`

Simple health check.

### Response

```json
{ "status": "ok" }
```

## Library entrypoint

The package exports `createCore`.

```js
import { createCore } from "rich-wind";

const app = createCore({
  config: { cacheTtlMs: 600000 },
  pluginTimeoutMs: 200,
  plugins: []
});

app.listen(3001);
```

`createCore` options:

- `config`: core limits/cache/rate-limit settings
- `plugins`: plugin or plugin array
- `pluginTimeoutMs`: default plugin hook timeout

## Config keys

`config` keys:

- `maxBodyBytes`
- `maxHtmlChars`
- `maxClassChars`
- `maxClassCount`
- `maxIdLength`
- `cacheMaxPages`
- `cacheTtlMs`
- `projectCacheTtlMs`
- `suggestLimit`
- `suggestFallback`
- `rateLimitWindowMs`
- `rateLimitMax`
- `rateLimitDisabled`
- `trustProxy`

Top-level option:

- `pluginTimeoutMs`
